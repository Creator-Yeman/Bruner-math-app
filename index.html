완전한 대수적 형식화

분배법칙을 통한 단계별 대수 전개 증명

기하학적 블록과 1:1 대응
1
정사각형 넓이의 정의 (거듭제곱)
(a + b)² = (a + b)(a + b)
2
첫 번째 괄호의 항들을 두 번째 괄호에 분배 (분배법칙)
= a(a + b) + b(a + b)
3
각 괄호를 전개하여 4개의 단항식으로 분해 (블록 4개)
= a·a + a·b + b·a + b·b
4
곱셈의 교환법칙 적용 (b·a = a·b)
= a² + ab + ab + b²
5
동류항 정리: ab + ab = 2ab (최종 공식 완성!)
(a + b)² = a² + 2ab + b²

제롬 브루너의 표상 양식 이론 (EIS 이론)

인지심리학자 제롬 브루너(Jerome S. Bruner)는 지식이 학습자의 인지 발달에 맞추어 활동적(Enactive) → 영상적(Iconic) → 기호적(Symbolic)의 3단계를 순차적으로 거칠 때 가장 깊이 내면화된다고 설명합니다.

1 활동적 표상 (Enactive Representation) - 신체적 조작

신체적 행동과 구체적인 물리적 조작을 통해 지식을 습득합니다. 1단계에서 학생들이 $a^2, ab, ba, b^2$ 4개의 블록을 직접 손으로 집어 큰 정사각형 틀에 맞추는 활동이 이에 해당합니다.

2 영상적 표상 (Iconic Representation) - 시각적 심상

실물 블록이 없어도 머릿속으로 떠올릴 수 있는 공간적 도해(Diagram)와 이미지로 개념을 구조화합니다. 2단계의 색상별 면적 도해와 분해 뷰를 통해 전체 면적이 네 부분으로 나뉨을 직관적으로 확인합니다.

3 기호적 표상 (Symbolic Representation) - 추상적 기호

논리적 기호와 수식 $(a+b)^2 = a^2 + 2ab + b^2$으로 형식을 일반화합니다. 조작과 시각적 경험이 선행되었기 때문에 학생들은 공식을 단순 암기하지 않고도 그 필연성을 확신하게 됩니다.

수학교육적 핵심: 중학생들이 흔히 범하는 "(a+b)² = a² + b²" 오류는 기호만 먼저 주입받아 발생합니다. 활동적·영상적 단계를 경험하면 누락된 $2ab$의 공간적 실체를 잊지 않게 됩니다.
